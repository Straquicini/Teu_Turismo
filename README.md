# ✈️ Agência de Viagens

## 📖 Sobre o projeto

Este projeto consiste no desenvolvimento de um **website de uma agência de viagens fictícia**, criado com fins académicos e de aprendizagem.

O principal objetivo do website é apresentar diferentes **destinos turísticos**, disponibilizando informações sobre os locais, pontos de interesse, cultura, gastronomia e outras características relevantes de cada destino.

O projeto **não representa uma agência de viagens real** e não possui sistema de reservas, pagamentos ou compra de viagens. O seu objetivo é exclusivamente demonstrar conhecimentos de desenvolvimento web e criação de interfaces.

---

## 🎯 Objetivos

Com o desenvolvimento deste projeto pretende-se:

* Criar um website relacionado com turismo e viagens;
* Apresentar diferentes destinos turísticos;
* Disponibilizar informações sobre os locais apresentados;
* Criar uma navegação simples e intuitiva;
* Desenvolver uma interface agradável e organizada;
* Praticar conceitos de desenvolvimento web;
* Trabalhar com imagens, textos e elementos multimédia;
* Desenvolver um website responsivo para diferentes dispositivos.

---

## 🌍 Conteúdo do website

O website apresenta diferentes destinos turísticos, permitindo ao utilizador consultar informações sobre cada local.

Entre as informações apresentadas podem encontrar-se:

* 📍 Localização;
* 🏛️ Pontos turísticos;
* 🏖️ paisagens;
* 📸 Imagens dos destinos;
* 💡 Curiosidades.

O conteúdo tem como objetivo proporcionar uma visão geral dos destinos e ajudar o utilizador a conhecer melhor cada local.
